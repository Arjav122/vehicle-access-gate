# Frontend

Next.js 14 app (App Router). UI code lives under `src/app` (routes), `src/components` (layout + UI), `src/lib` (API client), and `src/config` (shared constants such as the `/api/v1` prefix).

Project-wide docs, **`.env`**, **`requirements.txt`**, and the **database / Alembic** layout are described in the repository root [README.md](../README.md).
